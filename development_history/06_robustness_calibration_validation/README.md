# Robustness, calibration and validation

Adds sensitivity analysis, a calibration framework, real-data cleaning, multi-stint holdout validation, leave-one-stint-out cross-validation, and the final FastF1 real-data validation script.

Files in this stage are preserved with their original local filenames.

1. `sensitivity analysis and robustness testing.py`
2. `calibration and validation structure.py`
3. `real-data cleaning before calibration..py`
4. `calibrate on multiple tyre stints and validate on an entirely unseen stint.py`
5. `leave-one-stint-out cross-validation..py`
6. `Real data validation.py`
